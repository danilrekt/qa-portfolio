# QA Portfolio

Учебное портфолио начинающего QA-инженера (Manual QA + основы API-тестирования).

## Содержание
- `test-design/` — чек-листы, построенные по техникам тест-дизайна (классы эквивалентности, граничные значения)
- `bug-reports/` — баг-репорты, найденные на учебном приложении [saucedemo.com](https://www.saucedemo.com)
- `api-tests/` — коллекция Postman с автотестами (статус-коды, структура и типы данных)
- `sql/` — SQL-запросы: фильтрация, группировка, JOIN, поиск некорректных данных

## Навыки
Тест-дизайн, баг-репорты, Chrome DevTools (Network), Postman, SQL, Git
