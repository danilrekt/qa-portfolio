# BUG-01: Текст, введённый в поле Last Name, появляется в поле First Name на форме Checkout

**Приложение:** https://www.saucedemo.com
**Пользователь:** `problem_user`
**Окружение:** Google Chrome 154, Windows 10
**Severity:** Major

## Шаги воспроизведения
1. Открыть https://www.saucedemo.com и войти как `problem_user` / `secret_sauce`
2. Добавить любой товар в корзину
3. Открыть корзину и нажать **Checkout**
4. Кликнуть в поле **Last Name** и ввести `Ivanov`

## Ожидаемый результат
Введённый текст отображается в поле Last Name.

## Фактический результат
Поле Last Name остаётся пустым. Вводимые символы появляются в поле First Name.

## Обоснование severity
Пользователь не может указать фамилию и, следовательно, не может оформить заказ. Обходного пути нет.

## Вложения
Скриншот формы Checkout (ввод только в Last Name, остальные поля пустые).
