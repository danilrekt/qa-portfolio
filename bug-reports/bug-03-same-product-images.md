# BUG-03: На странице каталога у всех товаров отображается одинаковое неверное изображение

**Приложение:** https://www.saucedemo.com
**Пользователь:** `problem_user`
**Окружение:** Google Chrome 154, Windows 10
**Severity:** Minor

## Шаги воспроизведения
1. Открыть https://www.saucedemo.com
2. Войти как `problem_user` / `secret_sauce`
3. Открыть страницу каталога (открывается автоматически после входа)

## Ожидаемый результат
У каждого товара своё изображение.

## Фактический результат
У всех шести товаров одно и то же изображение (собака).

## Дополнительно (DevTools → Network → Img)
- Ошибок нет, запрос картинки возвращает статус 200
- Для всех товаров используется один файл: `/assets/sl-404-Cq1a9k9X.jpg`
- Проблема не в загрузке, а в том, что для товаров указан неверный файл

## Сравнение с эталоном
Под пользователем `standard_user` у товаров отображаются разные корректные изображения.

## Вложения
Скриншот страницы каталога.
