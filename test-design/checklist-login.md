# Чек-лист: форма входа (логин и пароль)

## Позитивные
- [ ] Валидный логин + валидный пароль → вход выполнен, открыта главная страница

## Негативные
- [ ] Валидный логин + неверный пароль → сообщение об ошибке, вход не выполнен
- [ ] Пустой логин + валидный пароль → ошибка
- [ ] Валидный логин + пустой пароль → ошибка
- [ ] Оба поля пустые → ошибка

## Граничные значения (минимальная длина пароля = 8)
- [ ] Пароль из 8 символов → принят
- [ ] Пароль из 7 символов → ошибка
- [ ] Пароль из 9 символов → принят

## Безопасность
- [ ] Пароль отображается точками, а не открытым текстом
- [ ] Пароль не виден в URL
- [ ] Ввод `' OR 1=1 --` не приводит ко входу и не ломает форму
- [ ] Сообщение об ошибке не раскрывает, что именно неверно: логин или пароль

## UI / удобство
- [ ] Очень длинный пароль не ломает вёрстку поля
- [ ] Отправка формы клавишей Enter работает
- [ ] Переход между полями клавишей Tab в логичном порядке
